Política de privacidade

Resumo: o LocalTusk não coleta nenhum dado sobre você. Tudo o que você cria fica no seu computador.

Última atualização: 12 de novembro de 2026

O aplicativo Uso da internet Seus dados Este site Contato

O aplicativo

  • Não existe conta, login ou cadastro.
  • Não há telemetria, análise de uso, relatório de falhas nem rastreadores. O app não envia informações sobre você, o seu computador ou os seus projetos.
  • Os serviços ficam só na sua máquina. Servidor web, PHP, MySQL, PostgreSQL, Redis e Mailpit escutam apenas no endereço local (127.0.0.1), então não ficam expostos à sua rede.
  • Os e-mails de teste não saem do computador. O Mailpit só captura as mensagens enviadas pelos seus projetos.

Como o código é aberto, você pode conferir tudo isso no repositório.

Quando o app usa a internet

O app só acessa a rede para baixar os componentes que você pede para instalar, e consulta a versão mais recente de alguns deles e a do próprio LocalTusk (para avisar quando há versão nova; dá para desligar em “PHP e ferramentas”). Isso acontece direto entre o seu computador e as fontes abaixo, sem passar por servidores do LocalTusk.

Esses servidores recebem o seu endereço IP, como em qualquer download, e têm as próprias políticas de privacidade. Além disso, o cliente de API do app envia as requisições que você configurar, para os endereços que você escolher.

Onde ficam os seus dados

Projetos, bancos de dados, backups, blueprints, coleções de API e configurações ficam na pasta ~/LocalTusk do seu computador. Nada disso é enviado a lugar nenhum.

Para apagar tudo, feche o app, mova-o para a Lixeira e remova a pasta ~/LocalTusk. Os backups e blueprints que você compartilhar como arquivo ficam sob o seu controle: quem os receber terá o conteúdo, inclusive o banco de dados que estiver dentro, então não compartilhe dados sensíveis.

Este site

  • Sem cookies, sem Google Analytics e sem pixels de anúncio.
  • Fontes e scripts são servidos pelo próprio site, sem pedir nada a redes de distribuição de terceiros.
  • O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso, como o endereço IP, conforme a política do GitHub.
  • O site não processa pagamentos nem guarda dados de quem doa. O QR code é uma imagem do próprio site e só leva ao LivePix quando você o escaneia ou clica no botão; a doação segue as regras e a política de privacidade do LivePix.
  • A página de download e o botão "Baixar" da página inicial consultam a API pública do GitHub para achar o arquivo da versão mais recente para o seu sistema. Esse pedido vai direto do seu navegador ao GitHub, e o resultado fica guardado só na sessão do navegador por alguns minutos.

Contato e mudanças

Dúvidas ou pedidos sobre privacidade: abra uma issue no GitHub. Se esta política mudar, a data no topo da página será atualizada e o histórico fica registrado no repositório.
