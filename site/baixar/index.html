Baixar o LocalTusk

Gratuito, sem conta e sem cadastro. O site reconhece o seu sistema e destaca o arquivo certo; se preferir outro, é só escolher abaixo.

macOS Principal Seu sistema

É o sistema em que o LocalTusk é feito e usado todo dia.

  • Apple Silicon (testado todo dia) e Intel
  • Sem Homebrew e sem Docker
  • PHP, bancos e ferramentas baixados pelo app
Apple Silicon (.dmg) Intel (.dmg)

Não consegui identificar o chip do seu Mac. Se ele for Intel, use o botão Intel.

Linux Beta Seu sistema

A pilha completa (PHP, MySQL, PostgreSQL, Redis, WordPress, HTTPS e rede) passou nos nossos testes no Ubuntu 24.04 (ARM64), mas ainda tem muito menos horas de uso que o macOS.

  • x86_64 e ARM64, com WebKitGTK 4.1 (o pacote libwebkit2gtk-4.1 da sua distribuição)
  • MySQL pede libaio e libnuma; o Redis, make e gcc

Windows Beta Seu sistema

A pilha completa (PHP, MySQL, PostgreSQL, Redis, WordPress, HTTPS e rede) passa nos testes automáticos no Windows, mas ainda tem poucas horas de uso real. Reporte problemas no GitHub.

  • Windows 10 ou 11, x64 (ARM ainda não)
  • PHP, bancos e ferramentas baixados pelo app
  • No Windows o Redis é o build comunitário do projeto redis-windows
Instalador (.exe)

Versões publicadas

Ainda não há instaladores publicados. Enquanto isso, dá para compilar o app a partir do código-fonte em poucos minutos, como mostrado abaixo.

Instalar

Windows: rode o LocalTusk_*_x64-setup.exe e siga o instalador. macOS: abra o .dmg e arraste o LocalTusk para a pasta Aplicativos. Linux: com o .AppImage, rode chmod +x LocalTusk_*.AppImage e abra o arquivo; com o .deb, sudo apt install ./LocalTusk_*.deb; com o .rpm, sudo dnf install ./LocalTusk-*.rpm.

Primeira abertura no macOS. O app ainda não é assinado nem notarizado pela Apple, então o macOS pode bloquear a primeira abertura. Clique com o botão direito no app, escolha Abrir e confirme. Se preferir pelo terminal: xattr -cr /Applications/LocalTusk.app.

Compilar a partir do código-fonte

Você precisa do Rust, do Node.js e do pnpm. No macOS, também das ferramentas de linha de comando do Xcode (xcode-select --install). No Linux, das bibliotecas do Tauri (no Ubuntu: sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libssl-dev patchelf build-essential).

# baixar o código
git clone https://github.com/jhonatanMP/localtusk.git
cd localtusk

# instalar dependências e gerar o app
pnpm install
pnpm tauri build

Os instaladores ficam em src-tauri/target/release/bundle/ (macos/LocalTusk.app e dmg/ no macOS; deb/, rpm/ e appimage/ no Linux).

Requisitos

SistemamacOS recente (Apple Silicon ou Intel) ou Linux (x86_64 ou ARM64) com WebKitGTK 4.1
Para usar o appmacOS: nada. Linux: libaio e libnuma (MySQL), make e gcc (Redis)
InternetSó para baixar PHP, bancos e ferramentas
Espaço em discoDepende das versões. O MySQL no Linux ARM64 tem cerca de 800 MB; no x86_64, 80 MB (8.4 em diante)

Desinstalar

Feche o LocalTusk e remova o app (no macOS, arraste para a Lixeira; no Linux, apague o AppImage ou use sudo apt remove localtusk / sudo dnf remove localtusk). Se quiser apagar também os seus projetos, bancos e backups, remova a pasta ~/LocalTusk. O app não espalha arquivos por outros lugares do sistema.
